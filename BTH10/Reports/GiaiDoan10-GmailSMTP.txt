Can cap nhat User Secrets:
- Host: smtp.office365.com
- Port: 587
- EnableSsl: true
- SenderEmail: diachi@outlook.com hoac diachi microsoft365
- UserName: diachi@outlook.com hoac diachi microsoft365
- Password: App Password neu tai khoan yeu cau MFA

Vi du:
dotnet user-secrets set "Smtp:Host" "smtp.office365.com" --project E:\2627ptpmql\BTH10\BTH7.csproj
dotnet user-secrets set "Smtp:Port" "587" --project E:\2627ptpmql\BTH10\BTH7.csproj
dotnet user-secrets set "Smtp:EnableSsl" "true" --project E:\2627ptpmql\BTH10\BTH7.csproj
dotnet user-secrets set "Smtp:SenderEmail" "diachi@outlook.com" --project E:\2627ptpmql\BTH10\BTH7.csproj
dotnet user-secrets set "Smtp:UserName" "diachi@outlook.com" --project E:\2627ptpmql\BTH10\BTH7.csproj
dotnet user-secrets set "Smtp:Password" "APP_PASSWORD" --project E:\2627ptpmql\BTH10\BTH7.csproj
